# Example

Every feature of `react-native-toastify-expo` in one screen: all types, title and action, promise toasts, top position, custom icon, show-until-hidden and hide all.

Open it in [Expo Snack](https://snack.expo.dev/@git/github.com/anuj-kumary/react-native-toastify:example). It runs in the browser, or on your phone with Expo Go.

This folder isn't part of the published package.
