# Example

Every feature of `react-native-toastify-expo` in one screen: all types, title and action, promise toasts, top position, custom icon, show-until-hidden, hide all, and the 1.3 features: progress bar, onPress, custom type, fully custom layout, keyboard avoidance, themes, no-duplicate ids, updating a toast in place and hold to pause.

Open it in [Expo Snack](https://snack.expo.dev/@git/github.com/anuj-kumary/react-native-toastify:example). It runs in the browser, or on your phone with Expo Go.

This folder isn't part of the published package.
